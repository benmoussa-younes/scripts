# Security policy

## Supported versions

The latest release receives fixes; older tags are kept as they are.

## Reporting a vulnerability

Report it privately through GitHub private vulnerability reporting
(<https://github.com/benmoussa-younes/scripts/security/advisories/new>) or by
email to <younes.benmoussa@pm.me>. Never in an issue or a pull request: write
the affected version, the impact and the smallest reproduction you have.

An acknowledgement follows as soon as the report is read; a fix ships in a new
tag whose release notes name the version that closes it. No bounty is offered.
